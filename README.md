# CS Endorsement: Python Workspace

Your workspace for Course 2 of First District RESA's Computer Science Endorsement. Every Course 2 lab runs here, in your own copy of this repository, opened in GitHub Codespaces. There is nothing to install, and it runs on a Chromebook.

## Start here (Lesson 1)

1. Click **Use this template**, then **Create a new repository**. Name it `cs-endorsement-python` and set it to **Public**.
2. In your new repository, click **Code**, open the **Codespaces** tab, and click **Create codespace on main**.
3. When VS Code opens in the browser, open `lab1/password_math.py` and press the Run button (top right), or type `python lab1/password_math.py` in the terminal.

## Saving your work

Work in a codespace is not on GitHub until you **commit** and **sync**. Open Source Control in the left sidebar, write a short message, click **Commit**, and then click **Sync Changes**.

A codespace stops after 30 minutes without activity. GitHub deletes a stopped codespace after 30 days. Anything you have committed and synced stays safe in this repository.

## Folders

- Later labs: each lab page tells you which file to create, and where.

## Public means public

Anyone can read a public repository. Never put a password, an API key, or student information in it. Lesson 4 shows where keys go instead.
